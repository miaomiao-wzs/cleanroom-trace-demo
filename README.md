# 净循：洁净服与鞋套追溯演示

用于制药 GMP 车间需求讨论的静态演示站点，包括 H5 交互原型、业务需求说明书和功能说明书。

## 在线访问

[打开演示与方案](https://miaomiao-wzs.github.io/cleanroom-trace-demo/)

## 内容

- `index.html`：演示首页及操作指南。
- `demo.html`：可新增模拟数据的 H5 原型。
- `business.html`：业务需求说明书，调研基线 V0.1。
- `functional.html`：功能说明书，调研基线 V0.1。
- `identification-costs.html`：[成本与效率两页摘要](https://miaomiao-wzs.github.io/cleanroom-trace-demo/identification-costs.html)，2026-10-19 V2.0。保留300套/3点/手机OCR预算，新增可调整的手工与系统记录效率示例；示例不是实测值。

无需安装依赖或构建。可下载仓库后用浏览器打开 index.html，或由静态服务器托管。

## 演示边界

所有数据均为模拟；新记录保存在访问者各自浏览器中，不会同步至服务器或其他人。请仅使用虚构编号及姓名。当前原型没有真实登录、电子签名、后台数据库或设备接口，不能作为正式 GMP 系统或已完成验证的证明。

页面中的次数和有效期是演示参数，正式要求需经现场调研和质量批准。成本对比页已于2026-10-16获授权公开。金额是预算假设，尚未取得供应商报价；已确认新制安装300个二维码、全厂共用3个操作点；灭菌方式、标签材质与安装人工报价仍待确认。本仓库不包含其他内部费用资料、其他项目资料或浏览器产生的记录。

### 自然月规则与破损处置

北京时间每自然月至少灭菌一次；本月无合格且已放行记录时提醒并禁止发放，保存有效期单独校验。破损可登记报废或返厂维修，两种状态均禁止发放；维修返回流程暂不体现。
